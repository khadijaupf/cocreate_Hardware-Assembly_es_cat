El montaje de ordenadores es una tarea esencial de un técnico de instalación de ordenadores. Es un proceso en el que se ensamblan todos los componentes internos necesarios para que el sistema informático sea funcional. Hay una secuencia adecuada para fijar cada componente al sistema informático.

Es un proceso sistemático. Comienza organizando las partes del ordenador.

 Materiales requeridos:

- Carcasa de ordenador con fuente de alimentación instalada
- Placa base
- CPU
- Ensamblaje de disipador de calor/ventilador
- Compuesto térmico
- Módulo(s) de RAM
- Separadores y tornillos para la placa base
- Pulsera y alfombrilla antiestática
- Kit de herramientas
